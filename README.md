# Synthetic Retail Sales Analysis

A reproducible R project that generates a fictional retail sales dataset, summarizes revenue and units sold by month, product, and category, and exports summary tables and charts.

> **Data note:** All records are synthetic and generated by the R script. No real customer, employee, or business data are used.

## Project objectives

- Generate a reproducible fictional retail dataset.
- Summarize sales by month, product, and category.
- Identify the highest-revenue product and category.
- Visualize monthly revenue and category revenue.
- Export the dataset and summary tables as CSV files.

## Requirements

- R
- RStudio Desktop (recommended)
- The `ggplot2` package

Install the required package in the RStudio Console:

```r
install.packages("ggplot2")
```

## Installation and setup

1. Clone or download this repository.
2. Open the project folder in RStudio.
3. Install `ggplot2` using the command above.
4. Open `sales_analysis.R`.
5. Set the working directory to the repository root, if it is not already set.

## Run the analysis

Run the script from the repository root:

```r
source("sales_analysis.R")
```

The script prints summary information in the Console and creates an `output/` folder containing:

- `synthetic_retail_sales.csv`
- `monthly_sales_summary.csv`
- `category_sales_summary.csv`
- `monthly_revenue.png`
- `category_revenue.png`

## Analysis workflow

1. Set a fixed random seed and create twelve monthly dates beginning in January 2025.
2. Define three fictional products, their categories, unit prices, and baseline sales volumes.
3. Generate monthly units sold and calculate revenue.
4. Aggregate revenue by month and aggregate units sold and revenue by category and product.
5. Print overall and grouped summaries.
6. Create and save monthly-revenue and category-revenue charts.
7. Export the dataset and summary tables as CSV files.

## Example: inspect an exported summary

After running the script, use R to read the category summary:

```r
category_summary <- read.csv("output/category_sales_summary.csv")
head(category_summary)
```
